Video Generation 数据管线与清洗策略调研

调研工业级 video generation 数据配方、清洗、标注、过滤、采样和训练阶段数据组织。重点覆盖 Sora、SVD、Movie Gen、Open-Sora Plan、HunyuanVideo、Wan、Cosmos/NeMo Curator，以及 Panda-70M、VidGen-1M、OpenVid-1M 等数据论文。

Executive Summary

高质量 video generation 的差异已经从“模型是否足够大”扩展到“数据工厂是否足够强”。头部报告普遍使用多阶段 data curation：shot splitting、motion/quality/aesthetic/OCR/watermark filtering、dense recaption、semantic dedup、concept balancing、duration/resolution bucketing 和 high-quality SFT。

可信来源分三类：工业基座报告、数据集/清洗论文、以及 NVIDIA NeMo Curator / Cosmos Curate 这类工程工具链。SVD 系统研究 data curation 对 video LDM 的影响；Movie Gen 和 Open-Sora Plan 公开了相当具体的过滤阶段；Panda-70M、VidGen-1M、OpenVid-1M 直接把视频数据质量和 caption 质量作为研究对象。

  • Pretrain: 大而杂，但必须经过基本质量、运动、去重和分桶。
  • SFT: 小而精，dense caption 和人工/强模型筛选比数量更重要。
  • Long video: 需要 long-take、multi-shot、entity recurrence、camera path 和 structured captions。
  • Audio-video: 还要加 audio quality、A/V sync、speech/lip、diegetic/non-diegetic 分类。

Data-Centric Papers

Stable Video Diffusion

系统研究 video LDM 的三阶段训练和 data curation。使用 cut detection、synthetic captions、CLIP/OCR/optical-flow/aesthetic filtering，并通过人类偏好比较不同筛选子集。

Panda-70M

从 HD-VILA-100M 中筛出高分辨率长视频，做 semantics-aware splitting；多个 cross-modality teacher 产 caption，再用人工小集训练 retrieval model 选最佳 caption。

VidGen-1M

明确指出低 caption 质量、低视频质量、temporal inconsistency、data imbalance 会限制 T2V。提出 coarse curation、captioning、fine curation。

OpenVid-1M

ICLR 2025，强调 high-quality million-scale 和 expressive captions；另外构建 433K 1080p HD subset，说明质量和文本信息利用比盲目规模更关键。

Filtering Strategy

过滤不应只写 pass/fail，而应保留可审计分数。质量、运动、OCR、水印、去重、语义分布都要进入 metadata。

  • Video quality: min side、bitrate、blur、noise、DOVER technical、aesthetic score。
  • Motion: optical flow、VMAF motion、static detector、jitter detector；过静和过快都不适合主训练。
  • Temporal consistency: shot boundary + LPIPS/CLIP/ImageBind 二次校验。
  • OCR/watermark: 边缘字幕可 crop；中心文字可能是语义，不应无脑删除。
  • Dedup: exact/near duplicate 与 semantic over-representation 分开处理。

Captioning Strategy

工业可用 caption 不是一个字符串，而是结构化描述：global caption、dense caption、segment captions、camera、style、entities、actions、OCR、安全标签和质量分数。

{
  "global_caption": "...",
  "segment_captions": [{"start": 0.0, "end": 2.0, "caption": "..."}],
  "camera": {"motion": "slow pan left", "shot": "medium shot"},
  "quality": {"aesthetic": 6.1, "technical": 0.83, "motion": 0.42},
  "bucket": {"aspect": "16:9", "duration": "8s", "resolution": "720p"}
}

Panda-70M 的经验很关键：开放域视频上没有单个 captioner 足够稳。video caption model、image VLM、ASR/OCR、LLM recaption 和人工小集训练的 caption ranker 应组合使用。

Implications For Wan

Smoke / Overfit Layer

1 条真实短视频，保留原 fps/resolution，派生标准化 mp4、latent cache、metadata json 和人工 caption，用来验证 loader、VAE、ckpt、TP/CP/recompute。

Small Curated SFT

100-1000 条 HQ 样本，做 scene split、OCR/watermark/motion/quality 过滤，VLM caption 后人工抽查。

Medium Pretrain

10K-1M clips，按 source/domain 分布写 manifest，保存 quality/motion/aesthetic/OCR/alignment scores 和 latent/text embedding cache。

Preference Layer

固定 prompt suite，比较 base Wan 与 finetuned Wan 的 paired outputs，审查 motion、identity、prompt adherence 和 temporal flicker。

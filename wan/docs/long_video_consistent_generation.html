Executive Summary

“长 video 且一致”不是单一能力：闭源产品靠 scaling + reference workflow，开源路线靠 diffusion forcing / context packing / memory bank，生产工作流仍大量依赖 keyframe storyboard 和逐 shot I2V。

闭源产品级

Sora 2、Veo 3.1、Runway Gen-4、Seedance 2.0、Kling 系列，产品能力强但训练细节少。

开源长视频

SkyReels-V2、FramePack、LongVie/LongVie2 适合本地研究和工程拆解。

研究范式

LCT、StoryMem、LoViC、MoC、StreamingT2V、FreeLong/FreeNoise 解决不同一致性瓶颈。

生产工作流

reference image、character sheet、keyframe storyboard、I2V per-shot、edit stitching 仍是最可靠路线。

Taxonomy

1. Scale Native Long-Context Transformer

代表 Sora、Sora 2、Veo、Seedance 2.0。通过大规模可变时长、分辨率、宽高比训练，让 object permanence、3D consistency、long-range coherence 从 scale 中出现。上限高，但训练细节通常闭源。

2. Reference / Ingredient Consistency Workflow

代表 Runway Gen-4、Veo 3.1 Ingredients。用 reference images / ingredient images 锚定角色、物体、背景和风格，是目前商业创作最实用的跨镜头一致性接口。

3. Autoregressive Chunking With Memory

代表 FramePack、SkyReels-V2、StreamingT2V、StoryMem、FilmWeaver、ShotStream。长视频被拆成 chunk 或 shot，下一段生成时带上 compressed context、keyframes、global memory 或 local cache。

4. Long-Context Tuning / Scene-Level Attention

代表 Long Context Tuning、LoViC、Mixture of Contexts。把 single-shot 模型扩成 scene-level model，让 attention 或 compressed context 跨多个 shots 建模。

5. Training-Free Extension

代表 FreeNoise、FreeLong、FreeLong++、Ouroboros-Diffusion。通过 noise rescheduling、sliding temporal attention、frequency blending 等推理技巧扩展短视频模型，成本低但上限有限。

6. Storyboard / Keyframe / I2V Workflow

先生成角色表、场景表、关键帧和镜头脚本，再逐 shot 做 I2V/extension，最后剪辑。这不是最优雅的模型能力，但目前最可靠。

Implications For Wan-Based Work

短期路线：生产工作流

  • Wan 做 shot-level generation。
  • 用 reference image / character sheet / fixed scene prompt anchors 维持一致。
  • 按 keyframe storyboard 逐 shot I2V，再做 transition smoothing 和 edit stitching。

中期路线：Wan Long-Video Extension

  • 加 chunk autoregressive generation、context frame encoder、first-frame/keyframe memory。
  • 加 latent memory bank、cross-chunk noise schedule、history-context guidance。
  • 把 DCP、SP/CP、recompute 和 long-video dataset resume 一起验证。

长期路线：Multi-Shot Wan Foundation

  • 数据需要 scene-level multi-shot videos，带 shot boundary、角色 ID、scene ID、camera language、dense captions。
  • 模型需要 scene-level attention 或 memory retrieval，支持 per-shot prompt + global story prompt。
  • 训练建议走 single-shot pretrain -> multi-shot long context tuning -> autoregressive/memory fine-tune -> preference/RL。

Video-Audio 联合生成基座模型综合方案

基于 Sora 2、Veo 3、Seedance 1.5 pro、LTX-2、Movie Gen Audio、UniVerse-1、JavisDiT++、HunyuanVideo-Foley 和 MMAudio 的公开资料，整理一个可工程落地的 video-audio joint foundation model 数据、模型、训练和评测配方。

Wan-based dual-stream DiT audio-video data AV-DPO

Executive Summary

推荐路线：以 Wan 类 video DiT 为视觉主干，加入较小 audio stream 和双向 cross-modal fusion；先训稳 V2A/T2A，再逐步解冻到 native T2AV，最后用 SFT + AV-DPO/RLHF 对齐同步、音质、画质和 prompt following。

闭源 native A/V

Sora 2、Veo 3、Seedance 1.5 pro/2.0 产品能力强，但细节不完整。Seedance 明确披露 dual-branch DiT、cross-modal joint、SFT/RLHF。

开源/开放报告

LTX-2、UniVerse-1、JavisDiT++、ProAV-DiT 给出了可复用模块：dual stream、SoE、TA-RoPE、modality CFG、AV-DPO。

V2A/Foley 强模块

Movie Gen Audio、Google V2A、HunyuanVideo-Foley、MMAudio 适合做 data engine、teacher、baseline 和 warmup stage。

Data Recipe

joint A/V 数据不是简单视频加音轨。必须构建 video-audio-caption triplets：video caption、audio caption、ASR transcript、audio event timeline、A/V sync score、diegetic/non-diegetic 标签、speech/lip 标签。

Model Recipe

推荐从 Wan 类 T2V 模型扩成 asymmetric dual-stream video-audio DiT。

Video Stream

大容量，Wan 初始化；保持 official checkpoint path 和 VAE latent shape 兼容。

↔

Audio Stream

较小容量，新初始化或 audio model 初始化；通过 audio AE latent 训练。

  • Cross-modal fusion: bidirectional cross-attention、temporal-aligned RoPE、cross-modality AdaLN、zero-init gated residual。
  • Audio representation: continuous audio latent autoencoder 优先；DAC/EnCodec 可作为替代 tokenizer 或 teacher。
  • CFG: modality-aware CFG，分别控制 text、video、audio、cross-modal guidance。
  • Condition dropout: drop text/audio/video/image/transcript/cross-modal links，以支持 T2AV/T2V/T2A/V2A/I2AV/A2V。

Evaluation And Acceptance

Metrics

Video: FVD、VBench、temporal flicker。Audio: FAD、CLAPScore、PESQ/STOI、clipping/noise。Sync: SyncNet/LSE-C/LSE-D、event onset error、lip-sync score。

Acceptance Ladder

Tokenizer reconstruction → V2A smoke → T2A smoke → T2V parity → T2AV smoke → 1-sample overfit → small SFT → bucket stress → preference win → distributed resume。

Recommended Wan-Based Milestones

  1. Milestone A: Wan + external Foley baseline，建立 A/V evaluation suite。
  2. Milestone B: 冻结 Wan，新增 audio stream，训练 V2A/T2A。
  3. Milestone C: 解冻后几层，训练 low-res native T2AV。
  4. Milestone D: HQ dialogue/foley/ambient SFT + AV-DPO。
  5. Milestone E: long/multi-reference AV，支持 voice/audio/image/video reference。

## 2026-05-19 Megatron-native distributed fix + dataloader

### DCP sharded-state blocker

TP2 训练 loss 正常下降，但旧 `wan_native_tp2_recompute_overfit_512x384_49f_official_1000_20260519`
DCP 推理 MSE 坏到 `1.92428768`。原因是 Wan 早期没有完整的 `sharded_state_dict`：
MCore TP linears 保存的是 rank-local shard，但普通 `nn.Module` 参数在 TP ranks 上用同一个
`replica_id=(0,0,0)` 保存；checkpoint validator 会拒绝一部分 checkpoint，没拒绝的也不能正确
reshard。

- `_Linear.sharded_state_dict()` 对 MCore `ColumnParallelLinear` / `RowParallelLinear` 委托原生实现。
- `WanModel.sharded_state_dict()` 递归保存普通模块，并且对 replicated tensors 同时传入 TP group 和 DP/CP group。
- 这样 replicated 权重被标为 TP replica，而 TP linears 保持 axis-sharded metadata。

### Dataloader / conditioner 结论

训练 path 不做 on-the-fly VAE/UMT5。原因：

- VAE/T5 是 frozen conditioner，重复计算只会浪费 GPU/CPU 和 I/O。
- on-the-fly 视频 decode + VAE + T5 会让 Megatron dataloader 延迟变成训练 step 的随机变量，DDP 下更容易 straggler。
- VAE/UMT5 大权重会增加每个训练 rank 的显存/内存压力，也和 TP/PP/CP/SP 主干并行没有直接关系。

当前实现：

- `WanJsonlDataset` 支持 `sample_path`、per-sample tensor path、和 production `shard_path/index`。
- safetensors shard 用 `safe_open(...).get_slice(key)[index]` 读取单条，不整 shard 反序列化。
- `.pt` shard 用 per-worker LRU cache；dataset pickle/fork 时清空打开文件句柄和 shard cache。
- `wan/scripts/pack_preencoded_dataset.py` 把预编码样本按固定 latent/context shape pack 成 safetensors 或 pt shards。
- `--wan-shard-cache-size` 控制 `.pt` shard LRU；production 推荐 safetensors shards。

CPU smoke 已覆盖 torch shard；pack script 功能测试已覆盖 safetensors shard读写。
